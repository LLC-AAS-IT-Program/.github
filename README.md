# AAS.IT | Information Technology

Welcome to the **AAS.IT GitHub organization** for the Information Technology program at **Lake Land College**.

This is our shared space for course repositories, student projects, team collaboration, and hands-on experience with the tools and workflows used in the IT industry.

## What's Here?

- **Class Repositories:** Assignments, examples, starter code, labs, and resources for individual courses.
- **Team Projects:** Repositories where students collaborate to plan, build, test, and document projects.
- **Shared Resources:** Notes, documentation, templates, and other materials that support learning across courses.
- **Student Work:** Projects that demonstrate skills and provide opportunities to practice real-world development workflows.

Repositories may be **public or private**, depending on the course or project. What you can access depends on your team membership and repository permissions.

## Classes and Teams

The organization uses **GitHub Teams** to help manage access and collaboration. You may be added to a team for a particular class, semester, or project.

Each repository has its own purpose and instructions. **Always read that repository's `README.md` first.** Your instructor's course policies and assignment directions take priority over any general guidance here.

## Getting Started

1. **Accept your invitation** to the GitHub organization, if one has been sent to you.
2. **Find your course or project repositories** under the organization's *Repositories* tab.
3. **Review the README and other instructions** in each repository before making changes.
4. **Clone or fork a repository** when directed, and complete your work using the workflow specified for that class or project.
5. **Submit your work as instructed**, whether that means a commit, branch, pull request, or another submission method.

If a repository or team you expect to see is missing, contact your instructor.

## Working Together

We use GitHub to practice collaboration as well as technical skills. When contributing:

- Write clear, descriptive commit messages.
- Keep changes focused and organized.
- Use branches and pull requests when requested by your instructor or project team.
- Document your work so others can understand and build on it.
- Treat feedback and code reviews as opportunities to improve.
- Respect teammates' contributions and communicate before making major shared changes.

### Academic and Professional Expectations

- Follow your course's academic integrity, collaboration, and AI-use policies.
- Only use or share materials in ways authorized by your instructor.
- Never commit passwords, API keys, access tokens, private credentials, or sensitive personal information.
- Be respectful and professional in code reviews, issues, discussions, and comments.

## Building a Portfolio

GitHub is also a place to develop skills you can demonstrate to future employers. Practice writing readable code, documenting decisions, organizing projects, and collaborating effectively.

**Before publishing or reusing class work**, make sure you have permission and that the repository contains no private or restricted materials.

## Questions?

For assignment requirements, repository access, team membership, or submission instructions, contact your **course instructor**. For project-specific questions, use the repository's issues or discussion space if your team has enabled them.
